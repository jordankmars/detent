# Lists

<Lead>A single wheel over any list.</Lead>

Long or short, plain or custom.

## Large list

Ten thousand looping values, with only eleven rows in the DOM. Setting `value` animates the wheel to the new item.

<Example name="large-list" />

## Custom rows

Rows from `renderItem`, spoken by name. The readout uses `onValueCommit`, so it updates when the wheel comes to rest.
