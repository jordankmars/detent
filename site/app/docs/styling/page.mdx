# Styling

<Lead>The same parts, in any look.</Lead>

## Variables

Set these on the Root or any parent.

| Variable | Default |
| --- | --- |
| `--detent-gap` | `2px` |
| `--detent-band-background` | `currentColor` at 9% |
| `--detent-band-radius` | `10px` |
| `--detent-band-inset` | `0` |
| `--detent-wheel-flex` | `1 1 0` |
| `--detent-item-font-size` | `21px` |
| `--detent-item-color` | `currentColor` at 55% |
| `--detent-disabled-opacity` | `0.5` |

## Parts

The parts are `data-detent-root`, `data-detent-band`, `data-detent-wheel` and `data-detent-item`, plus `data-selected` and `data-disabled`. The default styles have no specificity, so any CSS you write wins.

```css
[data-detent-band] { background: white; border-radius: 12px; }
[data-detent-wheel] { flex: none; width: 64px; }
[data-detent-item] { color: gray; font-size: 18px; }
[data-detent-item][data-selected] { color: black; }
```

## Good to know

- Cascade layers, including Tailwind's utilities, can't beat the defaults on the same property. Set a variable instead, like `[--detent-band-background:white]`.
- Properties detent doesn't set, like a border or shadow, work as usual.
